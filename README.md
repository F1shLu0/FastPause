# FastPause 🐟

一个 Windows 桌面小工具：把你的语录逐行放进剪贴板循环轮播。每按一次 `Ctrl+V` 粘贴当前行，并自动切换到下一行，到末尾自动回到第一行。

适用于需要在聊天框 / 编辑器里按顺序发送多行固定内容的场景（多行签名、快捷短语、文案轮播等）。

## ✨ 特性

- **单文件运行**：PyInstaller 打包为单个 exe，双击即用，无需安装 Python
- **极简交互**：启动即自动运行，`Ctrl+V` 粘贴当前行并自动切到下一行
- **可视化界面**：深色扁平 UI、无边框自绘标题栏、实时进度条与运行状态
- **编辑器内置**：语录直接在编辑窗口修改，输入停顿后自动保存（防抖 600ms）
- **自定义语录文件**：默认读取 exe 同目录的 `语录.txt`，也可在设置中指定任意路径
- **设置持久化**：文件路径、切换延迟保存在 `config.json`，下次启动自动恢复
- **高分屏适配**：启用 Per-Monitor DPI Aware，文字图标在高缩放比下依然清晰
- **窗口置顶**：所有窗口居中显示并置顶，点击哪个窗口哪个到最上层

## 🚀 快速开始

1. 下载或构建 `QuotePaste.exe`，放到任意文件夹
2. 在同目录准备 `语录.txt`（每行一条，空行自动忽略；可参考 `语录示例.txt`）
3. 双击运行，按 `Ctrl+V` 即可逐行粘贴

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+V` | 粘贴当前行，并自动切到下一行（循环） |
| `Ctrl+Q` | 退出程序 |

### 界面按钮

| 按钮 | 功能 |
| --- | --- |
| 暂停 / 继续 | 暂停或恢复 Ctrl+V 轮播监听 |
| 编辑语录 | 打开编辑器，输入后自动保存并实时生效 |
| 设置 | 修改语录文件路径、粘贴后切换延迟（毫秒） |

## ⚙️ 配置文件

首次在设置中保存后会生成 `config.json`：

```json
{
  "txt_path": "D:\\MyQuotes\\语录.txt",
  "delay_ms": 100
}
```

- `txt_path`：语录文件路径（默认为 exe 同目录的 `语录.txt`）
- `delay_ms`：粘贴动作后等待多少毫秒再切换到下一行，粘贴异常时可适当调大

## 🛠️ 从源码构建

依赖：Python 3.10+（Windows）

```bat
build.bat
```

或手动执行：

```bat
pip install -r requirements.txt
pyinstaller --onefile --noconsole --icon fish.ico --name QuotePaste quote_paste.py
```

构建产物位于 `dist\QuotePaste.exe`。

## ❓ 常见问题

**Q：粘贴出来的不是下一行？**
粘贴动作读取剪贴板需要时间，可在设置中把切换延迟调大（如 200ms）。

**Q：双击 exe 被杀毒软件拦截？**
PyInstaller 单文件应用偶发误报，添加信任即可。

**Q：窗口拖不动 / 找不到关闭按钮？**
按住顶部标题栏空白处拖动；右上角 `✕` 关闭，`─` 最小化；全局 `Ctrl+Q` 可随时退出。

**Q：程序异常退出了？**
查看同目录生成的 `error.log`，里面记录了完整堆栈。
